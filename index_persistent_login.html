AI generation format

Give an AI this instruction and ask it to return only valid JSON. Paste the result into the import box above.

Create a chapter topic list for my study-card website.

Return ONLY valid JSON in this exact structure:
{
  "subject": "Mathematics",
  "chapter": "Chapter name",
  "topics": [
    {
      "id": "unique-id",
      "title": "Topic title",
      "objective": "One concise, specific learning objective.",
      "prerequisites": []
    },
    {
      "id": "another-unique-id",
      "title": "Next topic",
      "objective": "One concise, specific learning objective.",
      "prerequisites": ["unique-id"]
    }
  ]
}

Rules:
- subject must be Mathematics, Physics or Chemistry.
- Use lowercase IDs with letters, numbers and hyphens; make each ID unique.
- Use prerequisites as IDs of topics in this chapter or topics already in my website.
- Use [] when a topic has no prerequisite.
- Keep topics small enough to study in one focused session.
- Order topics logically, but do not force a linear chain where topics can be studied independently.
- Return no Markdown fences or explanation; return JSON only.
